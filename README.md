# .github

Organization-wide defaults for this GitHub org: the profile README shown
on the org homepage (`profile/README.md`), plus default community-health
files (`CODE_OF_CONDUCT.md`, `SECURITY.md`, `PULL_REQUEST_TEMPLATE.md`,
`ISSUE_TEMPLATE/`) that apply to any repo in the org that doesn't define
its own.

`CONTRIBUTING.md` and `CODEOWNERS` are deliberately **not** here --
build/contribution instructions and path ownership differ per repo, so
those live in each repo individually.
